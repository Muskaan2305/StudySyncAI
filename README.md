# StudySyncAI

StudySyncAI is a full-stack MERN application designed to help students manage study tasks, organize subjects, and improve study productivity.

The project is currently under active development and is planned to include AI-powered study assistance features such as smart scheduling, note summarization, and personalized study recommendations.

## Tech Stack

### Frontend
- React
- Vite
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

---

## Current Features

- Create study tasks
- Subject tracking
- Task completion status toggle
- REST API integration
- MongoDB database storage
- Real-time frontend updates

---

## Planned Features

- AI study assistant
- Smart study planner
- Authentication and authorization
- Flashcards

- Dashboard analytics
